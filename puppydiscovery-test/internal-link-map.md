# PuppyDiscovery internal linking map

## Primary hierarchy
- Home → Puppies
- Home → Breeds
- Home → Find My Puppy
- Home → How It Works
- Home → Visit
- Puppies → current puppy detail pages
- Puppy detail → breed page
- Puppy detail → current puppies
- Puppy detail → Find My Puppy
- Breed → current inventory module
- Breed → Find My Puppy with breed preselected
- Breed → related breeds
- Locations → each geographic page
- Location → current puppies
- Location → breed directory
- Location → Find My Puppy
- Location → Visit / directions / call
- Unavailable puppy → same-breed page + Find My Puppy

## Indexation rules
Index: homepage, puppies, breed directory, strong breed pages, six location pages, verified current puppy pages, Find My Puppy, How It Works, Visit, Privacy, Terms.

Noindex: preview host, lead confirmation, internal search results, filtered parameter URLs, Operations, admin/private lead pages.

## Guardrails
Do not create breed × city combinations at scale. Add new location pages only when there is real search/conversion evidence and the page can provide distinct utility.
