# PuppyDiscovery SEO launch checklist

## Already implemented in the preview code
- 36 breed landing pages
- 6 geographic landing pages
- core browse/conversion/support routes
- unique titles and meta descriptions
- canonical URLs targeting PuppyDiscovery.com
- BreadcrumbList markup on breed/location pages
- FAQ markup on breed pages
- PetStore markup for the real Stuart store only
- static sitemap + dynamic puppy sitemap architecture
- robots template
- daily inventory sync foundation
- two-successful-run removal safeguard
- dynamic factual puppy page generation
- truthful zero-inventory states
- internal linking hubs
- Find My Puppy SMS fallback
- preview noindex protection

## Must happen before Google indexing is enabled
1. Connect PuppyDiscovery.com to the production deployment.
2. Resolve and validate the Noble Paw structured inventory source.
3. Verify generated puppy pages with real records.
4. Replace any design-test sample imagery/content on the homepage with synchronized inventory.
5. Run mobile/browser accessibility QA.
6. Add first-party event API and GA4 measurement ID.
7. Connect Search Console and submit sitemap-index.xml.
8. Remove preview-only noindex from the production build, not from the OEH test host.
9. Validate structured data with Google's Rich Results Test.
10. Confirm every indexable page returns 200 and every canonical resolves to the production domain.

## Expansion rule
Do not add thousands of city/breed permutations. Expand from Search Console queries, conversion data, inventory history, and genuine user utility.
